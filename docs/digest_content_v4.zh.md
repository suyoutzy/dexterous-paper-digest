# V4 日报内容与兼容方式

## 输出结构

基本信息包括中英文标题、作者、日期、来源、原文链接与工作模块名称。模块沿用现有六类，可标注多个有实质关联的模块，不显示数字编号。

每篇正文只有四部分，建议约 500–650 个汉字，允许按内容复杂度调整：

1. **研究问题与核心方法**：约 200–300 字，说明不足产生的原因、核心思想及实现步骤，区分创新与采用的已有技术。
2. **实验结果与局限**：约 100–150 字，保留必要条件、基线和单位；区分仿真/真机、百分比/百分点、作者局限/基于证据的判断。
3. **关键术语**：约 100–150 字，通常 2–4 个，必要时可增至 6 个；逐项解释英文术语、中文名称、含义及在本文中的作用。
4. **科研启发与阅读建议**：约 60–100 字；阅读等级为了解即可、选择性阅读或重点精读，章节和图号须有原文依据。

正文末尾显示实际阅读依据。篇幅超出时，优先压缩泛化启发、重复叙述和次要结果，不能靠机械截断核心方法满足长度限制。

## 读取与核验

检索、摘要评分、去重、候选数量与选择策略保持原有规则。只有入选论文进入全文读取：arXiv 优先公开 HTML，必要时读取 PDF；期刊尝试 Crossref 全文链接、出版方页面和 OpenAlex 指向的公开位置。

每篇访问有时间、大小与页数限制，重定向逐次检查公开 HTTPS 目标；不绕过付费墙或副本申请。不能获取可靠全文时回退摘要/元数据。匹配标题并确认方法与实验等正文内容后才标为全文；受长度、页数或文本提取覆盖限制则标为节选。PDF 是文本提取，不自动核验图片、公式或补充材料。

实验结果需要附一段输入资料中的短原文用于程序校验，结果数字必须出现在该片段中。作者明确局限也需对应原文；分析判断单独标注。此校验能阻止无来源片段或新增数字，不能替代对单位、基线、实验条件和结论的人工语义核对。校验用原文片段不会显示或写入投递归档。

内容生成仍只重试当前不合格批次一次；鉴权、网络和峰时异常沿用原规则。全文分析默认每篇一个请求，输入上限 100,000 字符，其中正文最多保留 90,000 字符；超出时跨全文取节选并明确标注，避免仅截取开头遗漏实验。原摘要评分继续使用 24,000 字符和每批最多五篇。

## 数据结构与字段映射

新生成记录使用 `content_version: 4`，模型输出与服务端来源信息分开校验。

| 原字段 | V4 字段或处理 | 兼容方式 |
| --- | --- | --- |
| 标题、作者、日期、来源、链接 | 保留原字段 | 来源信息和链接继续取自论文记录，不使用模型生成的链接 |
| `work_module` 单值 | `work_modules` 列表 | 保留首项到 `work_module` 供旧调用方读取；显示时优先列表 |
| `summary` | `research.problem/idea/implementation` | V4 新内容不用旧摘要替代；无版本号的旧记录仍走旧展示路径 |
| `why_for_you` | 删除独立章节，客观启发写入 `insight` | 旧记录保留原章节，不迁移或伪造新内容 |
| `learning_action` | 必要内容写入 `reading.focus` | 旧展示路径继续支持 |
| `evidence` | 原文片段校验、来源链接、`reading_basis` | 不生成独立“依据”正文段落 |
| `reading_depth` | `reading.level/focus` 与独立的 `reading_basis` | 阅读等级与实际资料范围分开；旧阅读范围字段继续可读 |
| 新增 | `experiments.setup/results/limitations` | 局限项区分 `author` 与 `analysis` |
| 新增 | `terms[].english/chinese/meaning/role` | 缺少含义或本文作用均不能通过新内容校验 |

没有 `content_version: 4` 的历史论文仍按旧格式展示，历史缺模块记录标为“未分类（历史记录）”。已有 Markdown 归档直接保留；已保存的待发送卡片与报告直接续传，不重生成、不补分类、不修改发送记录。新生成的模型输出必须通过 V4 校验，不能静默退回旧格式。

全文与 PDF 仅存在于生成步骤内存中，公开论文库、待发送数据与 GitHub 归档只保存必要元数据和生成后的科研速览。
